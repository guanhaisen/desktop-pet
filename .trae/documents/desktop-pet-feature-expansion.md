# 月薪喵桌面宠物 - 功能拓展计划（当前聚焦：功能 1 对话气泡系统）

## 概述

基于对现有项目代码的全景分析和 2024-2026 桌面宠物趋势调研，为「月薪喵」规划了 12 个功能拓展方向（详见后续梯队）。当前仅实施**功能 1：对话气泡系统**，作为所有文字类功能的基础设施。验证通过后再推进后续功能。

## 当前状态分析

### 已实现功能
- 透明无边框置顶窗口，120×120px GIF 动画
- 6 种状态：IDLE/WALK/INTERACT/DRAGGING/REMIND/SLEEP
- 优先级状态机驱动动画切换
- 鼠标交互：拖拽移动、左键互动、右键菜单
- 系统托盘：显示/散步/添加提醒/管理提醒/设置/退出
- 提醒系统：daily/weekly/none 重复，CRUD，到时播放提醒动画+托盘通知
- 配置持久化：窗口位置、缩放、自动行走、睡眠时间
- 双播放器：GifPlayer(QMovie) + FramePlayer(PNG序列帧)

### 架构可复用点（本功能相关）

| 架构能力 | 位置 | 拓展价值 |
|---------|------|---------|
| 透明窗口属性设置模式 | `src/pet_window.py` `FramelessWindowHint` + `WA_TranslucentBackground` | 气泡窗口可直接复用此模式 |
| 信号驱动解耦 | `src/app.py` 集中连接信号 | 气泡系统按现有模式接入 |

## 功能 1：对话气泡系统（详细实现方案）

### 做什么

在桌宠上方弹出透明气泡，显示文字（吐槽、倒计时、金句）。内容库以打工人/薪资为主题。气泡定时消失，位置跟随主窗口移动。

### 为什么

当前桌宠只能用动画表达情绪，气泡让它「会说话」。这是后续所有文字类功能（倒计时、时薪、AI 对话）的承载基础，应最先实现。

### 具体实现

#### 新增文件

**1. `src/ui/bubble.py` - 气泡窗口**

- `BubbleWindow(QWidget)`：无边框透明窗口，圆角背景，显示文字
- 窗口属性复用 `PetWindow` 模式：`FramelessWindowHint | WindowStaysOnTopHint` + `WA_TranslucentBackground`
- 用 `QPainter` 绘制圆角气泡背景（白色半透明），带小尾巴指向桌宠
- `show_message(text, duration_sec=4)` 方法：显示文字并启动定时器
- `QTimer` 控制显示时长，超时后隐藏
- `follow_pos(pet_x, pet_y, pet_width)` 方法：根据桌宠位置计算气泡位置（在桌宠正上方居中）
- 文字自动换行，气泡宽度自适应内容（有最大宽度限制）

**2. `src/content/quotes.py` - 金句库**

- 按场景分类的打工人/薪资主题金句：
  - `IDLE_QUOTES`：待机时随机吐槽（「今天又是为猫粮打工的一天」「老板还没走，我先装作很忙」）
  - `WALK_QUOTES`：散步时（「溜达溜达，假装在巡工」「巡视一下我的领地」）
  - `INTERACT_QUOTES`：被点击时（「别戳了别戳了，在打工呢！」「喵~ 你今天辛苦啦」）
  - `REMIND_QUOTES`：提醒时（「叮！该干活啦」「再不动起来就要长蘑菇了」）
  - `SLEEP_QUOTES`：睡眠时（「Zzz... 梦见加薪了...」「打工喵需要美容觉」）
- `get_random_quote(category)` 函数返回随机金句

#### 修改文件

**3. `src/pet_window.py` - 接入气泡**

- 新增 `bubble_requested = pyqtSignal(str)` 信号
- 在状态切换时（`_on_state_changed`）发出对应场景的气泡请求（低概率随机触发，避免每次切换都弹）
- 在拖拽/行走时通知气泡跟随位置（通过信号或直接调用）
- 新增 `show_bubble(text, duration_sec=4)` 公开方法，供 `PetApp` 调用

**4. `src/app.py` - 装配气泡系统**

- 实例化 `BubbleWindow`，连接 `PetWindow.bubble_requested` 信号
- 桌宠窗口移动时（拖拽/行走）同步气泡位置

#### 目录结构调整

```
src/
├── ui/                     # 新增目录
│   ├── __init__.py
│   └── bubble.py           # 气泡窗口
├── content/                # 新增目录
│   ├── __init__.py
│   └── quotes.py           # 金句库
└── ...（现有目录不变）
```

### 关键技术点

1. **气泡绘制**：用 `paintEvent` + `QPainter` 绘制圆角矩形 + 三角小尾巴，背景半透明白色
2. **位置跟随**：气泡在桌宠正上方，水平居中，`x = pet_x + pet_width/2 - bubble_width/2`，`y = pet_y - bubble_height - gap`
3. **文字自适应**：用 `QFontMetrics` 计算文字尺寸，气泡宽度 = min(文字宽度+padding, 最大宽度)，高度按换行计算
4. **触发频率控制**：状态切换时随机触发（如 30% 概率），避免气泡过于频繁打扰
5. **不阻塞动画**：气泡是独立窗口，不影响桌宠动画播放与交互

### 设计决策

- **气泡独立窗口**：不嵌入 PetWindow 内，避免动画层与文字层耦合，且可独立控制显示/隐藏
- **半透明圆角风格**：白色半透明背景 + 圆角 + 小尾巴，符合桌宠可爱风格
- **随机触发**：状态切换时低概率弹气泡，保持新鲜感但不打扰
- **手动触发接口**：提供 `show_bubble()` 方法，后续功能（倒计时等）可主动调用
- **金句分类**：按状态分类，气泡内容与当前动画状态语义一致

## 验证步骤

1. 启动程序，桌宠显示 idle 动画
2. 点击桌宠（触发 INTERACT），有概率弹出气泡显示互动金句
3. 拖拽桌宠时气泡跟随移动（若气泡正在显示）
4. 气泡显示约 4 秒后自动消失
5. 右键菜单切换睡眠/行走状态，有概率弹出对应场景金句
6. 气泡位置始终在桌宠正上方，不遮挡桌宠本体
7. 气泡显示期间桌宠动画正常播放，交互不受影响
